プライバシーポリシー / Privacy policy

最終更新日: 2026-10-28 / Last updated: 2026-10-28

使う人 / Who uses it

この OAuth クライアントは、Yuki Kataoka（youkiti）本人だけが、自分の Google アカウントで使います。ほかの人に提供していません。

This OAuth client is used only by Yuki Kataoka (youkiti), with his own Google account. It is not offered to anyone else.

扱うデータ / Data accessed

本人の Google ドライブのファイルとその情報（名前・大きさ・更新日時など）を読み、本人が指定したフォルダにファイルを書きます。

It reads files and file metadata (such as names, sizes and modification times) in the owner's own Google Drive, and writes files to a folder the owner chooses.

使い道と保存先 / Use and storage

データは、本人のコンピュータへのバックアップと、本人のドライブへの写しにだけ使い、本人のコンピュータに保存します。

The data is used only to back up the owner's files to his own computers and to copy files to his own Drive, and it is stored on his own computers.

第三者への提供 / Sharing

データを第三者に渡したり、売ったりしません。広告やアクセス解析には使いません。

The data is not shared with or sold to third parties, and it is not used for advertising or analytics.

Google API のデータの扱い / Google API data

Google API から受け取ったデータの使い方と移転は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
